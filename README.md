**JARVIS – Python AI Voice Assistant**
Jarvis is a Python-based AI voice assistant designed to listen, understand, and execute user commands through natural language interaction.
It combines speech recognition, machine learning, and system automation to deliver a smart desktop assistant experience.
This project is built as a learning-focused and resume-ready implementation of AI, NLP, and desktop automation using Python.
**Features**
Voice command recognition
AI-based intent classification using a neural network
Text-to-speech responses
Open websites and social media platforms
Open and close system applications
Control system volume (up, down, mute)
Monitor CPU usage and battery status
Personalized greetings and daily schedule assistant
**Tech Stack**
Programming Language: Python
AI / ML: TensorFlow, Keras
NLP: Tokenizer, Label Encoder
Speech Recognition: SpeechRecognition
Text-to-Speech: pyttsx3
Utilities: NumPy, psutil, pyautogui
